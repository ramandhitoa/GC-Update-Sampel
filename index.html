Pengaturan Google Spreadsheets Sync

Aplikasi ini mendukung sinkronisasi otomatis langsung ke **Google Spreadsheets** Anda menggunakan Apps Script Web App Endpoint.

Masukkan Web App URL Apps Script yang terkoneksi ke spreadsheet Anda.

Petunjuk Singkat Google Apps Script:
  1. Buka Google Sheets Anda, lalu klik menu Extensions > Apps Script.
  2. Tempelkan fungsi doPost(e) untuk menyimpan parameter laporan.
  3. Klik Deploy > New deployment > Web app. Set 'Who has access' ke Anyone.
  4. Salin Web App URL lalu tempelkan pada kolom di atas dan klik Simpan.
